# 🚗Car-MSRP-Prediction
Over view.. 

This project is a steamlit web that predicts the Manufacturer's Suggested Retail Price (MSRP) of a car using a machine learning model. Users can enter different car features, and the application estimates the car's price.
# ML Models
Throughout the exercise i used LinearRegression, DecisionTreeRegressor, and RandomForestRegressor ML model types.
